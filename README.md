# AI 协作开发管理

独立维护项目开发方法、角色分工、交付流程和验收规则的私有文档仓库。当前手册版本为 **v1.2**。

## 阅读方式

- 主文档：[AI 协作项目开发手册](index.html)。
- GitHub 仓库保存源文件，不直接呈现完整 HTML 页面。克隆或下载本仓库后，在浏览器打开根目录的 `index.html`，即可阅读完整排版；无需安装依赖。
- 本仓库保持私有，未启用 GitHub Pages 或其他公开网页托管。

## 手册内容

- 需求分析、范围确认与验收标准。
- P 产品与需求、A 架构与交付、B UI/UX、C 软件/固件、D 独立测试五个基础角色。
- 按需增加 E 应用工程师；自研电路或 PCB 时安排 H 硬件工程师。
- 软硬件交接、独立审查、样板实测和风险分级。
- 开发流程、任务卡、六类记录、并行规则及可复用角色说明。

## 目录

```text
index.html                 完整手册，内容的唯一维护源

```

## 维护规则

1. 手册内容只在 `index.html` 中维护；README 仅保留入口和摘要。
2. 涉及角色、流程或验收规则的修改，同步相关章节及版本标记。
3. 提交前检查本地链接、章节锚点和浏览器显示。
4. 不存放产品源码、设备日志、受限设计素材、密钥或账号凭据；具体项目的实施证据由各自项目管理。
5. 本仓库中的流程模板不构成刷写、采购、制板、公开发布或其他外部操作的授权。

本仓库为内部使用资料，不因存储于 GitHub 而获得公开分发授权。
